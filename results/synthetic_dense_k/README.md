# Dense-K Synthetic-Target Experiment — output package

Every target is an EML tree over `{x, 1}` with exactly `m = (K-1)/2` operators, so
expressibility is guaranteed and K is known by construction. A 0% convergence
result on such a target is search failure, not impossibility.

Generated by `research/synthetic/`. Full provenance, definitions and caveats:
**`run_metadata.json`**.

## Four things to read before analysing

1. **Rigidity does not predict beyond scale.** `conv ~ K` beats `conv ~ n_crit`
   (AUC 0.914 vs 0.747; deviance 3076 vs 4426 on equal df). Given K, α's
   coefficient is **positive** (+0.69, cluster-robust p = 0.022) — the opposite
   sign from what condition (ii) predicts — and g contributes nothing
   (p = 0.79/0.69/0.99). The K × rigid interaction is null (p = 0.604): there is
   **no** evidence the rigid subset declines faster. At K ≥ 21 rigid and
   non-rigid targets both sit at ~0%. Holds under all three α rules. The α, g
   and `n_crit` columns are reported as measured, but do not write conditions
   (ii)/(iii) as if they carry weight. Detail in
   `analysis_scale_vs_rigidity.txt`.

2. **`reviewer_ce` is an unremarkable member of its band** — 7/10 in A, 3/10 in
   B, ranking 17th and 19th of 31 K=7 targets, below the median in both. It is
   rigid (α ≥ 0.5 under all three rules) and gradient-free, so (i)–(iii) hold
   for it empirically. One neutral footnote: it is the single target exempted
   from the dead-subtree filter, because substituting 2.5 for the `x` at path RR
   leaves nMSE = 2.7e-7. It is exactly minimal at K=7 under the 1e-9 audit —
   that is a property of the working tolerance, not a defect in the example.

3. **Confound direction.** For K > 11 no minimality proof is available, so
   construction-K over-estimates true K, and over-estimated targets converge
   more easily than their nominal K implies. The observed drop is therefore a
   **conservative** estimate of the boundary — the true K₅₀ can only be lower.

4. **Two deviations from the main study's implementation.** Fitness is
   normalised to nMSE = MSE/Var(target) (a constant rescale, so selection order
   is unchanged; it makes the reference cell's absolute 1e-6/1e-5 thresholds
   mean the same thing across targets spanning many orders of magnitude), and
   evaluation is numpy-vectorised rather than per-point `cmath`. On 18,355
   random trees from the GP's own generator the evaluators disagree on 4.48%,
   but the best fitness any disagreeing tree achieved in either evaluator is
   nMSE = 0.296 — 5.5 orders above the convergence threshold, so no
   disagreement can flip an outcome. Search operators are `ga-lib` verbatim.

## Calibration against the main study

Two real targets have an **exact** synthetic counterpart, so they compare
function-for-function rather than by band placement:

| real target | K | synthetic | regime | real | synthetic | re-scored under main study's absolute rule |
|---|---|---|---|---|---|---|
| exp(x) | 3 | `K03_01` = `eml(x, 1)` | A | 1.00 | 1.00 | 1.00 |
| exp(x) | 3 | | B | 1.00 | 0.90 | 0.90 (p = 0.25) |
| ln(x) | 7 | `K07_07` = `eml(x, eml(eml(x,x), 1))` | A | 0.77 | 0.40 | 1.00 (p = 0.16) |
| ln(x) | 7 | | B | 0.20 | 0.40 | 1.00 (p < 0.001) |

For ln(x) the synthetic criterion is **75× stricter in absolute terms**
(Var = 0.0133, so nMSE ≤ 1e-6 means absolute MSE ≤ 1.3e-8 where the main study
allows 1e-6). Re-scored under the main study's own rule, regime A agrees;
regime B does not, and the residual is domain: real ln(x) is sampled on
(0.1, 5.0), including the steep near-zero region, versus (2, 3) here. `x1+x2`
(K=19) is two-variable and has no univariate counterpart — band placement only,
where it matches (0.000 real vs 0.007/0.000 synthetic).

Present the overlay as **same phenomenon, same transition location** — not as
identical rates.
